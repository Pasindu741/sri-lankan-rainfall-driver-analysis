# Sri Lankan Rainfall Driver Analysis

## Overview
This project studies how global, regional, and domestic climate indicators affect Sri Lankan rainfall patterns. It was completed as a 4-member group project for the ST3011 Statistical Programming course.

## Objectives
- Analyze how climate indicators influence Sri Lankan rainfall.
- Compare rainfall behavior across dry and wet zones.
- Study global, regional, and domestic rainfall drivers.
- Identify rainfall seasonality, monsoon effects, and rain shadow patterns.

## Climate Indicators Studied
- Global indicators: ENSO, SOI, Sunspot Activity
- Regional indicators: Indian Ocean Dipole (DMI), All-India Rainfall
- Domestic indicator: 850 hPa U-Wind

## Methods Used
- Exploratory Data Analysis
- Hypothesis Testing
- Correlation Analysis
- Data Visualization
- Time Series Analysis
- Lag Analysis

## Key Findings
- Regional-scale indicators such as Indian Ocean Dipole and All-India Rainfall showed important relationships with Sri Lankan rainfall.
- Rainfall behavior differed across dry and wet zones.
- Local wind effects and monsoonal patterns influenced rainfall distribution.
- Clear rainfall seasonality and rain shadow patterns were observed across Sri Lanka.
